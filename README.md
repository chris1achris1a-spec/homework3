## 三、實際搜尋測試結果

### 查詢 1：我想找味道清爽、不太濃烈的咖啡

1. 濃縮咖啡 (Espresso)
   相似度分數：0.658
   介紹：透過高壓熱水快速穿過研磨得極細的咖啡粉所萃取出的醇厚咖啡。它是許多義式咖啡的基底，表面會有一層濃郁的咖啡脂（Crema），口感強烈、層次豐富，帶有咖啡豆最純粹的香氣與苦甜風味。適合喜歡強烈咖啡口感的人。

2. 美式咖啡 (Americano)
   相似度分數：0.624
   介紹：以義式濃縮咖啡為基底，加入大量熱水稀釋而成。保留了濃縮咖啡的香氣，但大幅降低了苦澀與濃烈感，口感清爽順口，適合喜歡單純咖啡風味、需要提神但不愛太濃烈口感的飲用者。

3. 冷萃咖啡 (Cold Brew)
   相似度分數：0.620
   介紹：用冷水或室溫水將粗研磨咖啡粉長時間浸泡萃取而成。因為沒有高溫加熱，酸澀感較低，口感順滑，帶有甘甜尾韻，適合冰飲。

4. 拿鐵咖啡 (Cafe Latte)
   相似度分數：0.590
   介紹：源自義大利的經典飲品，由濃縮咖啡與大量熱牛奶混合，並在頂部鋪上一層薄薄的奶泡。牛奶的甜味完美中和了咖啡的苦味，口感溫潤柔滑，是接受度極高的咖啡飲品，常配有美麗的拉花藝術，非常適合咖啡新手。

5. 摩卡咖啡 (Cafe Mocha)
   相似度分數：0.589
   介紹：結合了濃縮咖啡、熱牛奶以及巧克力醬或可可粉，頂端常擠上鮮奶油並撒上巧克力碎屑。摩卡融合咖啡的醇厚與巧克力的香甜，是一款偏甜點風格的咖啡。
